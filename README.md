# MySQL Database Concepts Assignment

A practical implementation of database management concepts using MySQL. This project demonstrates database design, data manipulation, query optimization, transaction controls, and security configurations.

## 🚀 Key Features Implemented

* **DDL Operations:** Table creation (`Departments` & `Employees`) with strict integrity constraints (`PRIMARY KEY`, `FOREIGN KEY`, `UNIQUE`, `CHECK`, `DEFAULT`).
* **DML Operations:** Data insertion, updates (conditional salary increases), and structured record deletion.
* **DQL Queries:** Advanced data retrieval including aggregate functions, `GROUP BY` analytics, pattern matching (`LIKE`), and relational table joins (`JOIN`).
* **TCL Transactions:** Safe transaction blocks handling updates, custom `SAVEPOINT` implementation, and controlled rollbacks.
* **DCL Security:** Database security simulation through `CREATE USER`, privilege assignment (`GRANT`), access auditing, and privilege revocation (`REVOKE`).

## 🛠️ Technology Used
* **Database Management System:** MySQL
* **IDE/Client:** MySQL Workbench
